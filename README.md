# 📝 Notes App

A simple and modern **Notes App built with Flutter and Hive**.
This project demonstrates how to build a local-first notes application with persistent offline storage.

## ✨ Features

* 📝 Create new notes
* ✏️ Edit existing notes
* 🗑️ Delete notes
* 📖 View saved notes
* 💾 Persistent local storage
* 📱 Offline functionality
* ⚡ Fast and lightweight database using Hive

## 🛠️ Tech Stack

| Technology  | Purpose                |
| ----------- | ---------------------- |
| **Flutter** | Mobile app development |
| **Dart**    | Programming language   |
| **Hive**    | Local NoSQL database   |

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/bilalnasar924-debug/notes_app_hive.git
```

### 2. Open the project

Open the project in **Android Studio** or **VS Code**.

### 3. Install dependencies

```bash
flutter pub get
```

### 4. Run the application

```bash
flutter run
```

## 💾 Local Storage

This application uses **Hive** to store notes locally.

Hive provides:

* Fast read/write operations
* Offline data persistence
* Lightweight NoSQL storage
* Simple integration with Flutter
